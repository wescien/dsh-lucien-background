# 宇宙无敌背景 · Cosmic Background

给 **DeepSeek Harness** 的桌面端加一层会动的壁纸：7 套场景 + 星尘 / 流星 / 光标光晕 / 雪花，全部由 CSS 渐变与 Canvas 现场绘制，**无图片、无网络请求、无额外依赖**。

界面原本不透明的底色被改成半透明（只改写 `--dsw-alias-bg-base`、`--dsw-specific-sidebar-fill` 与 `body` 背景），壁纸因此能透出来，正文仍压在最上层。

---

## 效果

- **7 套场景**：极光 / 深海 / 星云 / 晨曦 / 余烬 / 森野 / 极地
- **4 类附加效果**：星尘、流星、光标光晕、雪花，各自独立开关
- **实时可调**：速度、对比度、饱和度、文字遮罩、柔化，改一下立刻生效
- **7 组预设**：极夜 / 深海 / 晨曦 / 余烬 / 森野 / 极地 / 霓虹，鼠标悬停 160ms 即可预览
- **自动模式（默认关）**：按时间切换场景；帧率过低时自动降级

## 安装

插件以 **Cordis bundle** 形式提供，需要在 DSH 桌面端的 profile（默认 `%USERPROFILE%\.dsh\profiles\desktop`）里注册为依赖与行。

**方式一：插件管理器**

把本仓库作为 bundle 安装（支持 git 源）：

```text
install_bundle  →  github:wescien/dsh-lucien-background
```

**方式二：手动**

```powershell
cd $env:USERPROFILE\.dsh\profiles\desktop
pnpm add github:wescien/dsh-lucien-background
```

然后把包名 `@local/aurora-background` 加入该 profile `package.json` 的 `dsh.profile.bundles` 数组，重启桌面端；或在「插件」页找到「宇宙无敌背景」这一行直接启用。

> 包名固定为 `@local/aurora-background`：客户端模块的 id 必须与包名一致，改名会导致模块加载不到。

## 7 套场景

七套背景共用同一个构造函数 `layeredScene()`，每套都是四层叠加，保证观感一致：

1. **整层不透明渐变底**（每套独立配色）
2. **整层斜向渐变色板**，160% 尺寸、13s 缓慢平移 —— 屏幕上的颜色主要来自这一层
3. **三团柔光云**（58px 模糊，64s / 82s / 96s 各自漂移）
4. **soft-light 叠加 + 顶部高光 + 底部暗角**

浅色主题刻意压住了两层白色叠加（soft-light 0.32、顶部高光 0.20），否则整屏会被冲白，看起来像没生效。文字遮罩默认 0。

| 名称 | 特征 |
|---|---|
| 极光 | 青绿 / 紫罗兰光带缓慢漂移 |
| 深海 | 蓝色纵深 + 焦散光呼吸 |
| 星云 | 双云团 + 细尘 |
| 晨曦 | 暖橙 → 玫粉渐变 + 太阳光晕 |
| 余烬 | 暗红 / 橙光，炉火余温 |
| 森野 | 墨绿 + 青苔光雾 |
| 极地 | 冰蓝缎带 + 斜向雪雾 |

### 流星细节

单一冷白色，不是一条等宽线：

| 部位 | 做法 |
|---|---|
| 尺寸 | 每颗随机：长度 240–1000px、头宽 4–16px（幂律分布，小流星多、火流星少） |
| 联动 | 越大越慢、寿命越长（1.55–2.5s），头部光晕随头宽放大 |
| 形状 | 从头部宽度一路收窄到尖端，细锥（不做宽体，避免"扇形"） |
| 拖尾 | 柔锥 alpha 0.5 → 0，覆盖全长 |
| 亮芯 | 纯白，覆盖前 62%，带 42Hz 细微闪烁 |
| 头部 | 光晕 5.4×头宽 + 白色热核 0.72×头宽 |
| 暗描边 | 整条 0.9×宽、alpha 0.2，浅色主题靠它才看得见 |
| 入场 | 180ms 淡入，光晕先 1.5× 后收回 |
| 余迹 | 消失后留 480ms 残影，alpha 0.3 淡出 |

## 全局旋钮与预设

速度 0.2–3×（换算成所有动画周期）、对比度 0.6–1.8、饱和度 0.4–1.8、文字遮罩 0–60%（默认 22%，越高文字越清晰、壁纸越淡）、柔化 0–12px（整层壁纸模糊）。

预设：极夜 / 深海 / 晨曦 / 余烬 / 森野 / 极地 / 霓虹，悬停 160ms 预览，移开还原，点击应用。

## 自动模式（默认关）

- **按时间自动切换**：5–9 晨曦、9–16 极光、16–19 余烬、19–23 星云、23–5 极地
- **低帧率自动降级**：连续 10 秒低于 40fps 时，星尘减半并关闭光晕（只降一次）

## 设置入口

- 设置 → **宇宙无敌背景**（主面板，顶部有实时摘要行）
- 插件 → 宇宙无敌背景 →「包含的组件」一行，可整体开关
- 面板「高级」：运行自检（36 项）、复制 / 粘贴配置、恢复默认（带确认）、实时帧率、两个自动模式开关

## 设置存储

`localStorage['dsh.cosmic.settings']` 一份 JSON，通过同源 `CustomEvent: dsh-cosmic:settings` 同步到各个挂载点；可用「复制配置」导出、「粘贴配置」导入。

## 稳定性设计

- **单例**：重建前先移除同名宿主节点，重复挂载不叠层
- **还原**：注入前快照 `body` / `html` 背景与两个 token，卸载时按快照恢复
- **释放**：rAF、`resize` / `pointer` / 主题 / 可见性监听、定时器、`CustomEvent` 全部在 effect 清理中释放
- **省电**：窗口失焦或页面隐藏时，CSS 动画 `animation-play-state: paused`、粒子 rAF 停止；回来自动恢复
- **降级**：`prefers-reduced-motion` 下不启动粒子循环，只画一帧（可用「强制动画」覆盖）
- **容错**：`localStorage` 损坏或字段越界时回退默认值（自检里有专门断言）
- **看门狗**：粒子循环若因异常停摆，700ms 内自动重启

## 已知限制（实测）

壁纸要透出来，前提是它上方的容器是半透明的。实测（`elementFromPoint` 采样）：

| 区域 | 计算背景 | 壁纸可见 |
|---|---|---|
| 侧栏 | `rgba(248,249,253,0.12)`（本插件改写） | 是 |
| 对话区 | `section.hSzSIW_root` → `rgb(249,250,251)`（组件内硬编码） | 否 |
| 输入框 | `[data-composer-card]` → `rgb(255,255,255)`（硬编码） | 否 |

对话区与输入框的颜色不走 `--dsw-*` token，因此改 token 无效。要让它们也透出，只能改宿主组件或按语义属性硬盖（如 `[data-composer-card]`），后者会在宿主升级后失效，默认不做。

## 动态与系统设置

Windows 的「动画效果」关闭时，浏览器会报告 `prefers-reduced-motion: reduce`。插件默认跟随无障碍规范暂停所有动画，但那会让星尘、流星看起来"没生效"，因此提供一个开关：

- 设置页 → 动态区 → **强制动画**（默认开）
- 关掉它 = 跟随系统（系统开减少动态时，只画一帧静态星图）
- 旧配置会在首次加载时自动迁移为"强制动画"；挂载时就读取这项偏好，不会先画一帧静止图

星点额外画了一层暗色光晕，流星下方有一条暗色底线，保证在浅色/浓色壁纸上都能看清。

## 卸载与清理

移除本 bundle 会：删除 `#dsh-cosmic` 宿主层、注入的 keyframes 样式、按快照还原 `body` / `html` 背景与两个 token，并断开全部监听与定时器。
