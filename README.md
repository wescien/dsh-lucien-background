# 宇宙无敌背景（@local/aurora-background）

DeepSeek Harness 的动态壁纸插件：把界面背后那层固定背景换成会动的场景。界面原本不透明的底色被改成半透明（只覆盖 `--dsw-alias-bg-base`、`--dsw-specific-sidebar-fill` 和 `body` 背景），壁纸因此能透出来，正文仍压在最上层。

## 场景结构

七套背景共用同一个构造函数 `layeredScene()`，每套都是四层叠加，保证观感一致：

1. **整层不透明渐变底**（每套独立配色）
2. **整层斜向渐变色板**，160% 尺寸、13s 缓慢平移 —— 屏幕上的颜色主要来自这一层
3. **三团柔光云**（58px 模糊，64s / 82s / 96s 各自漂移）
4. **soft-light 叠加 + 顶部高光 + 底部暗角**

浅色主题刻意压住了两层白色叠加（soft-light 0.32、顶部高光 0.20），否则整屏会被冲白，看起来像没生效。文字遮罩默认 0。

## 7 套背景

| 名称 | 特征 |
|---|---|
| 极光 | 青绿 / 紫罗兰光带缓慢漂移 |
| 深海 | 蓝色纵深 + 焦散光呼吸 |
| 星云 | 双云团 + 细尘 |
| 晨曦 | 暖橙 → 玫粉渐变 + 太阳光晕 |
| 余烬 | 暗红 / 橙光，炉火余温 |
| 森野 | 墨绿 + 青苔光雾 |
| 极地 | 冰蓝缎带 + 斜向雪雾 |

全部由 CSS 渐变 + keyframes 绘制，无图片、无网络请求。

## 4 类附加效果（同一个插件内置）

- **星尘**：四角星精灵图；宝石 / 暖金 / 冰蓝 / 雪白 4 套配色；16–140 颗；鼠标 96px 内带阻尼吸引
- **流星**：并发 ≤ 3，出现频率 0.2–3×
- **光标光晕**：320px 柔光跟随，强度 0.04–0.30
- **雪花**：密度 0.2–2×，带横向摆动

## 全局旋钮

速度 0.2–3×（换算成所有动画周期）、对比度 0.6–1.8、饱和度 0.4–1.8、文字遮罩 0–60%（默认 22%，越高文字越清晰、壁纸越淡）、柔化 0–12px（整层壁纸模糊）。

## 预设

7 组 + 随机：极夜 / 深海 / 晨曦 / 余烬 / 森野 / 极地 / 霓虹。悬停 160ms 预览，移开还原，点击应用。

## 自动模式（默认关）

- **按时间自动切换**：5–9 晨曦、9–16 极光、16–19 余烬、19–23 星云、23–5 极地
- **低帧率自动降级**：连续 10 秒低于 40fps 时，星尘减半并关闭光晕（只降一次）

## 面板摘要

设置页顶部有一行实时摘要：`当前：极光 · 星尘 56 颗 · 雪花 关 · 流星 关 · 光标光晕 关 · 文字遮罩 22%`，改任何一项立即反映。

## 配置入口

- 设置 → **宇宙无敌背景**（主面板）
- 插件 → 宇宙无敌背景 →「包含的组件」两行：**宇宙无敌背景**（场景）/ **宇宙星尘**（粒子），各自独立开关
- 设置页「高级」：运行自检、复制 / 粘贴配置、恢复默认（带确认）、实时帧率、两个自动模式开关

## 设置存储

`localStorage['dsh.cosmic.settings']` 一份 JSON；场景模块写、粒子模块读，通过同源 `CustomEvent: dsh-cosmic:settings` 同步。可用「复制配置」导出、「粘贴配置」导入。

## 稳定性

- **单例**：重建前先移除同名宿主节点，重复挂载不叠层
- **还原**：注入前快照 `body` / `html` 背景与两个 token，卸载时按快照恢复
- **释放**：rAF、`resize` / `pointer` / 主题 / 可见性监听、定时器、`CustomEvent` 全部在 effect 清理中释放
- **省电**：窗口失焦或页面隐藏时，CSS 动画 `animation-play-state: paused`、粒子 rAF 停止；回来自动恢复
- **降级**：`prefers-reduced-motion` 下不启动粒子循环，只画一帧
- **容错**：`localStorage` 损坏或字段越界时回退默认值（自检里有专门断言）
- **自检**：模块热重载时自动跑 34 项断言（冷启动不跑），结果写入 `<profile>/cosmic-background-report.json`；离屏渲染探针同时验证设置页与真实点击

## 文件

- `client.js` 场景引擎 + 设置页（`settings.section`）+ 自检
- `index.js` 主机侧：`POST /cosmic/report` 接收自检结果
- `cordis.patch.yml` 插入两行（本包 + `@local/aurora-stars`）

## 已知限制（实测）

壁纸要透出来，前提是它上方的容器是半透明的。实测（`elementFromPoint` 采样）：

| 区域 | 计算背景 | 壁纸可见 |
|---|---|---|
| 侧栏 | `rgba(248,249,253,0.12)`（本插件改写） | 是 |
| 对话区 | `section.hSzSIW_root` → `rgb(249,250,251)`（组件内硬编码） | 否 |
| 输入框 | `div.GRgSLq_card[data-composer-card]` → `rgb(255,255,255)`（硬编码） | 否 |

对话区与输入框的颜色不走 `--dsw-*` token，因此改 token 无效（已实测：覆盖 `--dsw-alias-bg-layer-1/2` 后这两处颜色不变）。要让它们也透出，只能改宿主组件或按语义属性硬盖（如 `[data-composer-card]`），后者会在宿主升级后失效，默认不做。

## 卸载与清理

移除本 bundle 会：删除 `#dsh-cosmic` / `#dsh-cosmic-stars` 两个宿主层、注入的 keyframes 样式、按快照还原 `body`/`html` 背景与两个 token，并断开全部监听与定时器。
## 动态与系统设置

Windows 的「动画效果」关闭时，浏览器会报告 `prefers-reduced-motion: reduce`。插件默认按无障碍规范暂停所有动画，但那会让星尘、流星看起来"没生效"，因此提供一个开关：

- 设置页 → 动态区 → **强制动画**（默认开）
- 关掉它 = 跟随系统（系统开减少动态时，只画一帧静态星图）
- 已有的旧配置会在首次加载时自动迁移为"强制动画"；挂载时就会读取这项偏好，不会先画一帧静止图

星点额外画了一层暗色光晕，流星下方有一条暗色底线，保证在浅色/浓色壁纸上都能看清。
